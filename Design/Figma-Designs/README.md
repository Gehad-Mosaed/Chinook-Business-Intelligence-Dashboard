This folder contains the Figma design layouts for the Chinook Business Intelligence Dashboard.

The project consists of four main dashboard pages, each focusing on a different aspect of business performance and insights:

Finance: Focuses on financial performance and sales analysis.

Music Anatomy: Explores music catalog data, including artists, albums, tracks, and genres.

Customer Insights: Focuses on customer analysis and purchasing behavior.

Executive Insights: Provides a high-level overview of key business performance indicators.

These designs serve as the visual blueprint for the Power BI dashboard implementation.
